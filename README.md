# QG Pessoal — versão web

Abra em **https://megabot2.github.io/qg-web/**

Este repositório tem só o código da página (gerado a partir do projeto qg-pessoal). Seus dados não ficam aqui: o app salva no repositório privado `qg-dados`, usando a chave que você cola nas Configurações, guardada só no seu navegador.
